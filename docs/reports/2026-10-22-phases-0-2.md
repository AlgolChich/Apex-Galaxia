## Verified how

- `pnpm install && pnpm build && pnpm test`: 14 test files, 82 tests, all green; `pnpm lint` clean; a clean clone from the branch builds and passes.
- Exports: the EPUB test checks the stored `mimetype` entry, container, OPF, nav and chapter XHTML by reading the package back; the DOCX test reads `word/document.xml`; both sample projects exported from the CLI.
- Canvas: ordering, links, templates, promotion and collapse tested; AI actions validated on a scripted model; `apex canvas` smoke-tested on the Russian sample.
- Muse loop on a scripted model: draft → critic (revise) → revise → critic (pass), only the quoted span changed; the fast preset skips the critic.
- Autonomous run on a scripted model: two chapters unattended with chronicle, summaries, book export and report; a simulated crash on chapter two resumes without rewriting chapter one; long stories stop at the outline gate and continue after approval; a tiny budget pauses the run.
- `apex eval --no-critic` from the CLI: 100% lint coverage on the fault set, report written; `/improve` on a scripted model writes a variant, re-runs and never touches shipped files.
- Linter: every rule id is covered by a seeded case in `evals/fault-set/`; the two clean control passages produce no hits; both sample chapters lint clean.
- Harness pipeline end to end on a scripted model: contract retry, suggestion, accept, chronicle proposal and apply, summary cache, critic, rewrite diff, describe, lesson, budget stop.
- MCP server over stdio with no API key: create project → Bible entry → plan (d20 rolled and logged) → chapter with a contract violation and then a valid one → accept → chronicle propose/apply → summary → lint → research sanitizer → model tool fails with `ADAPTER_ERROR`.
- CLI smoke: `apex new`, `bible add/list`, `open`, `lint` (exit code 2 on errors), `inspect`, `chronicle --full` on both samples.
- Hook: fed PostToolUse JSON by hand; silent on non-chapter files, reports hits on a faulty chapter.
