# Маяк

## Summary

Маяк на песчаной косе в сорока километрах от посёлка; катер раз в неделю, зимой по льду.

## True now

Лампа работает от дизеля; второй дизель разобран. Продуктов на девять дней.

## Details

Башня в двадцать два метра, жилой дом на два окна, сарай с насосом, причал из трёх свай. Радио ловит только по вечерам. Вода из колодца с привкусом железа.

## Secrets

За южным мысом есть бухта, где можно спрятать лодку.
