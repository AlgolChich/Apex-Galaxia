# Apex Galaxia v0.1.0

The first pre-release: the core, the `apex` command line, headless mode for Claude Code and the desktop app. Every story is a folder of Markdown and YAML on your machine; the narrator's prose stays a suggestion until you accept it.

- Story Bible with bilingual aliases and activation, the chronicle that keeps long stories consistent, the Gwen narrator profile (storytellers with a real d20, fate harshness, ratings, hard limits).
- Write in four modes with streaming suggestions, Describe, Rewrite as per-paragraph diffs, the bilingual AI-tell linter, the critic and the bounded revision loop, autonomous runs with resume and an ASK gate for irreversible choices.
- The desktop app: a CodeMirror prose editor, project tree, panels, command palette, wizards, Bible, chronicle, plan, canvas and run views, Gwen's chat panel, light and dark themes, Russian and English interface.
- Exports to Markdown, DOCX and EPUB; eval suite and planner evals; manuscript import.

Installers below: `.deb` / `.rpm` / `.AppImage` for Linux, `.msi` / `.exe` for Windows, `.dmg` for macOS. Unsigned builds warn once on first launch; see `docs/release.md`. The app needs an Anthropic API key for the model-backed features; everything else works offline.

# Apex Galaxia v0.1.0

Первый предварительный выпуск: ядро, командная строка `apex`, безголовый режим для Claude Code и настольное приложение. Каждая история — папка с Markdown и YAML на вашем компьютере; проза рассказчицы остаётся предложением, пока вы её не примете.

- Библия истории с двуязычными псевдонимами и активацией, летопись, которая держит длинные истории в согласии, профиль рассказчицы Гвин (рассказчики с настоящим d20, жёсткость судьбы, рейтинги, жёсткие границы).
- Четыре режима письма с потоковыми предложениями, «Описать», «Переписать» как диффы по абзацам, двуязычный линтер ИИ-следов, критик и ограниченный цикл правок, автономный режим с возобновлением и шлюзом ASK для необратимых решений.
- Настольное приложение: редактор прозы на CodeMirror, дерево проекта, панели, палитра команд, мастера, виды Библии, летописи, плана, канваса и прогона, чат Гвин, светлая и тёмная темы, русский и английский интерфейс.
- Экспорт в Markdown, DOCX и EPUB; набор евалов и евалы планировщика; импорт рукописи.

Инсталляторы ниже: `.deb` / `.rpm` / `.AppImage` для Linux, `.msi` / `.exe` для Windows, `.dmg` для macOS. Неподписанные сборки один раз предупредят при первом запуске; см. `docs/release.md`. Для функций с моделью нужен ключ Anthropic API; всё остальное работает без сети.
